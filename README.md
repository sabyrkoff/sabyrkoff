# sabyrkoff

React + TypeScript application powered by Vite.

## Development

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` runs Biome's linter.
- `npm run format` formats the project with Biome.
- `npm run check` checks formatting, lint rules, and imports with Biome.

Use `@/` to import files from `src/`.
